# V4.3 — Site Internet

Version propre de travail, reconstruite à partir du projet fourni.

## Objectif

Le système d'édition visuelle n'utilise plus les sélecteurs `nth-of-type()` pour les nouvelles publications.

Chaque élément éditable possède désormais une identité stable `data-vce-id`.

### Éléments canoniques

- `hero-title-prefix`
- `hero-brand-name`
- `hero-tagline`
- `hero-subtitle`
- `hero-badge-text`
- `hero-designer-location`
- `hero-background-media`
- `logo-boutique-image`
- `logo-boutique-name`
- `logo-boutique-secondary`
- `logo-gite-image`
- `logo-gite-name`
- `logo-gite-secondary`
- `navbar-order-button-text`
- `story-title`
- `story-text-1`
- `story-text-2`
- `product-<id>-image`
- `product-<id>-name`
- `product-<id>-description`
- `product-<id>-price`
- `product-<id>-discover`

## Persistance

Le panneau de personnalisation et l'éditeur visuel utilisent le même snapshot :

`brandData + editorConfig + publishedAt`

Ordre de sauvegarde :

1. `/api/site-config` (runtime)
2. `/api/site-publish` (GitHub)
3. Vercel redéploie le bundle

Le fichier `src/data/site-content.generated.ts` fourni ici est déjà nettoyé et ne contient aucun ancien bloc `element-<timestamp>` ni aucun `nth-of-type()`.

## Important

Ne pas récupérer un ancien `site-content.generated.ts` depuis une version V2/V3/V4 précédente.

Le fichier fourni dans cette archive est volontairement la base propre.

## Déploiement

Cette archive contient le projet complet. Tu peux remplacer le contenu du dépôt par celui de cette archive, conserver tes variables d'environnement Vercel, puis pousser sur `main`.

Les secrets ne sont pas inclus.
